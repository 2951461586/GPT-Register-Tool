# v2026.08.15.1 发布说明

本补丁版本修复账号测活重登后的状态残留，并恢复 GitHub Actions 的完整验证链路。

## 账号测活

- “账号测活”设置弹窗宽度固定为 740 px。
- AT 401 账号重登并通过 HTTP 200 探活后，清除优惠状态中已过期的“AT失效”标记。
- 保留原优惠检测详情，后续可重新执行“查优惠”刷新资格。

## 构建与 CI

- 环境预检和桌面发布脚本支持 `global.json` 的 `latestFeature` SDK 前滚策略。
- 修复 GitHub Windows runner 安装 .NET SDK 10.0.400 时被错误判定为与 10.0.300 不兼容的问题。
- 桌面程序通过标准发布脚本重新生成到 `dist/net10`。

## 验证

- Python 全量测试、Python 编译检查、架构扫描和敏感字段扫描。
- .NET 全量测试与 `SmsWorkbench/build_dotnet.ps1` 标准发布构建。
- 安装器、便携 ZIP 和 SHA-256 清单来自同一次 `v2026.08.15.1` 构建。
